# Security and customer data handling

## Access
Employees access customer data only for an active support case or onboarding project.
Production credentials are never shared in chat, email or documents.

## Retention
Raw synced data is retained for 90 days. Aggregated dashboard data is retained for the life of the contract.
On contract end, customer data is deleted within 30 days unless the customer requests an export.

## Requests from customers
Security questionnaires are handled by the security team within 10 business days.
Do not answer questions about certifications from memory; refer them to the security team.
